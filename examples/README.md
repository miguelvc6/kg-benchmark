# Synthetic example

These tiny JSONL files illustrate the canonical case, world-state, and disposition shapes. They are synthetic fixtures,
not research data and not large enough to satisfy paper selection quotas.

- `cases.jsonl`: one A-box case and one T-box case.
- `world-state.jsonl`: canonical keyed context rows.
- `dispositions.jsonl`: complete final-disposition coverage for the example cases.
